# math2

Решения листка № 2 **«Комплексные числа. Геометрия комплексных чисел»**.

В [Листок_2.ipynb](Листок_2.ipynb) сохранены код, пояснения, результаты вычислений и рисунки для заданий 2.1–2.10. Оба пункта с номером 2.10, включая логарифмическую спираль, выполнены.

| Задания | Тема |
| --- | --- |
| 2.1–2.3 | Формы записи комплексных чисел и корни |
| 2.4–2.5 | Области на комплексной плоскости и уравнение окружности |
| 2.6–2.8 | Корни многочлена, гамма-функция, комплексный определитель |
| 2.9 | Множества Жюлиа для четырёх отображений |
| 2.10 | Проекция кривых и спирали на сферу Римана |

Для просмотра достаточно открыть ноутбук. Для повторного расчёта установите библиотеки и запустите все ячейки по порядку.

```sh
python -m pip install -r requirements.txt
python -m jupyter lab
```
