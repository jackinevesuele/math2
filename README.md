# math2

Решения листка № 1 **«СЛАУ, матрицы, квадратичные формы»**.

Основной файл — [Листок_1.ipynb](Листок_1.ipynb). В нём выполнены все задания
**1.1–1.20**, сохранены результаты вычислений, пояснения и рисунки.
Разделения на варианты в исходном листке нет.

## Содержание

| Задания | Тема |
|:---:|:---|
| 1.1–1.3 | Системы линейных уравнений и свободные параметры |
| 1.4–1.10 | Матрицы, определители, обратные матрицы, суммы степеней |
| 1.11–1.12 | Биномиальные коэффициенты и матрицы Адамара |
| 1.13–1.15 | Собственные значения, минимальный многочлен, ортонормированный базис |
| 1.16–1.20 | Главные оси, кривые второго порядка, определённость и эквивалентность форм |

В № 1.6 максимум определителя подтверждён точным конечным перебором.
В № 1.7–1.8 большие матрицы обрабатываются по структуре, без создания
плотных массивов. В № 1.9 проверена минимальность найденного индекса.

В исходном PDF в № 1.20 напечатано `2x₁`. Это выражение содержит линейный
член и не является квадратичной формой. В работе отдельно рассмотрены
буквальная запись и возможная опечатка `2x₁²`.

## Просмотр и запуск

Для просмотра откройте ноутбук на GitHub: результаты уже сохранены.
Для повторного выполнения нужен Python 3.12 и JupyterLab:

```bash
python -m venv .venv
```

Активация среды в Windows PowerShell:

```powershell
.\.venv\Scripts\Activate.ps1
```

В Linux/macOS:

```bash
source .venv/bin/activate
```

После активации:

```bash
python -m pip install -r requirements.txt
python -m jupyter lab
```

Откройте `Листок_1.ipynb` и выберите **Kernel → Restart Kernel and Run All Cells**.
Все расчёты выполняются локально; загрузка данных из сети не требуется.
Полный перебор в № 1.6 может занять несколько секунд в зависимости от компьютера.
